Política de privacidad

Última actualización: 24 de octubre de 2026

Antes de publicar: el responsable de la aplicación debe completar el correo de contacto oficial al final de esta política y revisar que la descripción corresponda a la entidad que publicará la app.

Datos que utiliza la aplicación

El directorio de sedes se incluye en la aplicación. No es necesario crear una cuenta. La aplicación no tiene un servidor propio ni almacena perfiles, historial de búsqueda o ubicación.

Si eliges “Usar mi ubicación actual”, el navegador o Android solicita permiso de ubicación. Las coordenadas se usan en el dispositivo para calcular cuál sede está más cerca; la aplicación no las envía a un servidor propio ni las guarda.

Si escribes una ciudad o dirección para buscar una sede cercana, el texto se envía a Nominatim, servicio de geocodificación de OpenStreetMap, para obtener coordenadas. Se aplican la política de privacidad de OpenStreetMap Foundation y sus condiciones de uso.

Servicios de terceros

La aplicación puede cargar mapas de Google Maps y abrir enlaces externos para indicaciones. Al cargar o abrir esos servicios, Google puede recibir datos técnicos como la dirección IP y datos del dispositivo, conforme a la política de privacidad de Google.

La web se puede alojar en GitHub Pages. GitHub puede procesar datos técnicos de las solicitudes según su declaración de privacidad.

Permisos y control

La ubicación es opcional. Puedes denegar o revocar el permiso desde los ajustes del navegador o del dispositivo y seguir buscando sedes por nombre o dirección. La geolocalización del dispositivo requiere una conexión segura HTTPS, disponible en GitHub Pages y en la aplicación Android.

Menores y cambios

La aplicación es un directorio informativo de eventos. La entidad responsable debe definir y publicar cualquier regla aplicable a menores de edad. Esta política puede actualizarse si cambian las funciones o los servicios utilizados; se publicará la fecha de actualización en esta página.
